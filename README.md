# RETAILPRO — PROYECTO DE DATA ANALYTICS
## DESCRIPCIÓN DEL PROYECTO
RETAILPRO ES UN PROYECTO DE ANÁLISIS DE DATOS ORIENTADO AL ESTUDIO DEL COMPORTAMIENTO DE LAS VENTAS DE UNA EMPRESA COMERCIAL.
EL OBJETIVO PRINCIPAL ES TRANSFORMAR LOS DATOS EN INFORMACIÓN ÚTIL PARA COMPRENDER EL DESEMPEÑO COMERCIAL, IDENTIFICAR OPORTUNIDADES DE MEJORA Y FACILITAR LA TOMA DE DECISIONES.
## OBJETIVOS
- ANALIZAR EL COMPORTAMIENTO DE LAS VENTAS.
- IDENTIFICAR LOS PRODUCTOS CON MAYOR FACTURACIÓN.
- ESTUDIAR LA EVOLUCIÓN DE LAS VENTAS A LO LARGO DEL TIEMPO.
- ANALIZAR EL DESEMPEÑO DE LOS DISTINTOS CANALES DE VENTA.
- CONSTRUIR INDICADORES QUE PERMITAN EVALUAR EL RENDIMIENTO COMERCIAL.
## HERRAMIENTAS UTILIZADAS
- **POSTGRESQL:** CONSULTAS SQL, FILTROS, AGRUPACIONES Y RELACIONES ENTRE TABLAS.
- **POWER BI:** MODELADO DE DATOS Y CREACIÓN DE VISUALIZACIONES.
- **POWER QUERY:** LIMPIEZA Y TRANSFORMACIÓN DE DATOS MEDIANTE PROCESOS ETL.
- **DAX:** CREACIÓN DE MEDIDAS E INDICADORES PARA EL ANÁLISIS DE VENTAS.
## TRABAJO REALIZAD
EL PROYECTO CONTEMPLA DISTINTAS ETAPAS DEL PROCESO DE ANÁLISIS:
1. CONSULTA Y EXPLORACIÓN DE DATOS MEDIANTE SQL.
2. INTEGRACIÓN DE INFORMACIÓN UTILIZANDO JOIN.
3. LIMPIEZA Y TRANSFORMACIÓN DE DATOS MEDIANTE POWER QUERY.
4. CONSTRUCCIÓN DEL MODELO DE DATOS EN POWER BI.
5. CREACIÓN DE UNA TABLA CALENDARIO.
6. DESARROLLO DE MEDIDAS DAX PARA ANALIZAR EL COMPORTAMIENTO DE LAS VENTAS.
## INDICADORES DESARROLLADOS
- TOTAL DE VENTAS.
- VENTAS ONLINE.
- VENTAS ACUMULADAS EN EL AÑO (YTD).
- VENTAS DEL AÑO ANTERIOR (LY).
- PORCENTAJE DE CRECIMIENTO ANUAL.
## CONSULTAS SQL
LAS CONSULTAS SQL SE DESARROLLAN EN POSTGRESQL.
PARA EJECUTARLAS:
1. ABRIR POSTGRESQL MEDIANTE PGADMIN.
2. SELECCIONAR LA BASE DE DATOS CORRESPONDIENTE AL PROYECTO.
3. ABRIR EL QUERY TOOL.
4. CARGAR EL ARCHIVO SQL QUE SE DESEA EJECUTAR.
5. EJECUTAR LA CONSULTA Y REVISAR LOS RESULTADOS.
## MODELO Y VISUALIZACIÓN
EN POWER BI SE TRABAJÓ CON UN MODELO DE DATOS COMPUESTO POR TABLAS DE DIMENSIONES Y UNA TABLA DE HECHOS.
TAMBIÉN SE REALIZARON TAREAS DE LIMPIEZA, TRANSFORMACIÓN, CREACIÓN DE RELACIONES Y DESARROLLO DE MEDIDAS DAX.

## ESTADO DEL PROYECTO
PROYECTO DESARROLLADO COMO PARTE DE UNA FORMACIÓN EN DATA ANALYTICS. SU OBJETIVO ES APLICAR LOS CONOCIMIENTOS ADQUIRIDOS EN SQL, ETL, MODELADO DE DATOS Y VISUALIZACIÓN.
